
## Basic stuff

- Mod Key + Arrow Keys = Navigation 
- Mod Key + Shift + Arrow Keys = Move windows
- Mod Key + Q = Kill window
- Mod Key + Enter = Terminal


- Mod Key + 1,2,3,4 = Switch to workspace
- Mod Key + Shift + Number = Move window to a workspace
- Shift + Alt + Number = Switch to workspace with the window selected
